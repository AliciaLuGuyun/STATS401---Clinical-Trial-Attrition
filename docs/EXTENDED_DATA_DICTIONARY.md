# Extended research-edition data dictionary

All outputs generated by `scripts/deepen.py` from the immutable raw snapshot and validated interim CSVs. Source-study join: `protocolSection.identificationModule.nctId` ↔ `nct_id`. No patient-level inferences. Empty CSV cells / JSON null mean unavailable or not derived; Boolean false is a failed rule, not a missing count. Source cells are preserved as strings alongside numeric parsing; missing, nonfinite or nonnumeric strings are not coerced to zero.

## New trial fields

| Field | Raw path / derivation | Meaning and qualification |
|---|---|---|
| enrollment / enrollment_type | `protocolSection.designModule.enrollmentInfo.count/type` | Registry enrollment, not flow STARTED |
| allocation | `protocolSection.designModule.designInfo.allocation` | All eligible trials RANDOMIZED by design |
| protocol_arm_count | length of `protocolSection.armsInterventionsModule.armGroups` | Missing list → null, not 0 |
| intervention_types | sorted unique `.interventions[].type` in that module | Combined set; can include comparators/co-interventions |
| interventions | `.interventions[].name` joined for display | Original names; not a harmonized drug taxonomy |
| start_date | `protocolSection.statusModule.startDateStruct.date` | Exact original precision retained |
| calendar_span_days | completion date minus start date, only if both YYYY-MM-DD and nonnegative | Recruitment/study calendar span, not treatment exposure |
| calendar_span_flag | exact_dates or missing_partial_or_invalid_dates | No date imputation |
| site_count | length of `protocolSection.contactsLocationsModule.locations` | Empty → null; count of listed locations, not audited active sites |
| phase_III_present | PHASE3 in `designModule.phases` | Combined II/III counts as true |
| enrollment_minus_started | enrollment minus validated summed STARTED | Diagnostic discrepancy, not a correction rule |
| number_randomized | deliberately null | No common count safely derived from current flow/registration fields |
| reported_zero_completions | usable AND completed == 0 | Reporting-anomaly sensitivity flag; does not assert an error |
| pair_status | explicit eligibility / failure category | Does not force interpretation of unpaired trials |

Existing trial, arm and reason fields retain definitions in `DATA_DICTIONARY.md`. Original units (participants, rates 0–1, difference percentage points) are unchanged.

## Reporting indicators

All have one row per eligible NCT ID. They summarize the raw study, even if no attrition is derived.

- `participant_flow`: nonempty groups and periods.
- `completion_counts_present`: exactly one numeric COMPLETED numSubjects entry, without numUnits, for every raw period × flow group. Does not itself check completed ≤ started or phase comparability.
- `reason_table_present`: at least one nonempty dropWithdraws array in any period.
- `reason_counts_present`: at least one reason entry, all reported numSubjects numeric and no numUnits. Does not require every arm to report reasons or require reconciliation.
- `outcome_module_present`: nonempty outcomeMeasures array.
- `numeric_primary_results`: any PRIMARY outcome measurement with a finite numeric value. It can have missing/ambiguous group structure or heterogeneous endpoints.
- `single_period`, `exact_arm_mapping`, `usable_attrition`: analytical rules, separate from presence of source reporting. True in only 150, 95 and 82 trials respectively.

`reporting_by_year.csv` counts these indicators by registered study completion year, including a missing-year row. It describes this selected results-bearing cohort, not historical registry reporting prevalence.

## Primary outcome extraction

Raw path `resultsSection.outcomeMeasuresModule.outcomeMeasures[outcome_index]`; retain only `type == PRIMARY`. Original zero-based index retained, not reindexed after filtering. Metadata: title, description, timeFrame, populationDescription, paramType, dispersionType, unitOfMeasure, group count, numeric cell count, analysis count. No endpoint selection or sign standardization.

`primary_outcome_cells.csv` key: NCT ID + outcome_index + class_index + category_index + measurement_index. Raw pointer continues `.classes[class_index].categories[category_index].measurements[measurement_index]`. Preserve groupId, original group title, raw value, finite numeric value, spread, lower/upper limits, class/category labels. `denominators_json` preserves original outcome-level `denoms` so participants analyzed can be distinguished from flow STARTED; denominators are not automatically substituted into any effect formula.

`scale_title_screen` uses title regex (MADRS/Montgomery; HAM-D/Hamilton/HDRS; other/unclear). It is a search aid, not clinical harmonization. `change_title_screen` checks the word change. Exact outcome-to-flow mapping requires equal group counts, one unique normalized title match per group, and a bijection. FG/OG IDs are never equated.

`outcome_review_candidates.csv`: belongs to one of 38 valid flow pairs; MADRS title + change title; MEAN or LEAST_SQUARES_MEAN; exact group link; exactly two numeric cells total and two groups. Review is still required for repeated/cross-class cells, treatment periods, populations, direction and estimates/uncertainty. No treatment effect is calculated.

## Exploratory exports

| File | Unit / key | Measures |
|---|---|---|
| trial_metrics | NCT ID | All eligible studies, extended fields and inherited QC |
| arm_metrics | NCT ID × flow group × period | Existing arm counts, original labels/types, reason reconciliation |
| differential_attrition | NCT ID | Both arm fractions, signed/absolute pp difference and direction (tolerance 1e-9 pp for equality) |
| arm_mapping_audit | NCT ID × raw flow group | Exact match count, label/type, complete trial bijection, period count |
| variable_coverage | variable × eligible/usable cohort | total, present, missing, percent present |
| subgroup_summary | variable × original category | eligible and usable n, usable fraction, participant-pooled rate, trial median/Q1/Q3 |
| rank_associations | numeric field × anomaly sensitivity | complete n, missing/excluded n, Spearman using average ranks for ties |
| model_coefficients | sensitivity × term | OLS pp coefficient, HC3 SE, trial-bootstrap percentile limits, replicates, seed |
| model_diagnostics | sensitivity × NCT ID | observed/fitted pp, residual, leverage |
| reporting_by_year | completion year, including null | eligible/usable/pair/reason/numeric-primary counts |

Model parameters, interpretation, sensitivity and limitations are documented in `FINAL_PROJECT_PROGRESS.md`. `final/data.json` packages these same outputs plus original-label details; it contains no raw contacts or patient records. Display code does not derive a new treatment effect.
